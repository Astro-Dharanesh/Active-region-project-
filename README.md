# Solar Data Analysis & Processing

A collection of Python scripts developed for **solar data retrieval, processing, and analysis**, with a focus on working with observations from NASA's **Solar Dynamics Observatory (SDO)** and solar-wind measurements from **OMNI**.

The repository contains scripts for automated FITS-image retrieval, solar active-region analysis, and OMNI data processing.

## Research Context

This repository supports my research and learning in **solar physics, heliophysics, and astronomical data analysis**. The workflows are designed to facilitate the processing of solar observations and the investigation of solar active regions and their connection with the near-Earth solar-wind environment.

## Repository Contents

| Script                                     | Purpose                                         |
| ------------------------------------------ | ----------------------------------------------- |
| `AR_analysis.py`                           | Analysis workflow for solar active regions      |
| `OMNI.py`                                  | Processing and analysis of OMNI solar-wind data |
| `Solar_fits_image_downloader_automated.py` | Automated retrieval of solar FITS images        |
| `solar_fits_image_downloader.py`           | Solar FITS-image downloading workflow           |
| `solar_fits_image_retrieve.py`             | Retrieval of solar FITS data                    |

## Data & Instruments

The repository works with solar datasets associated with:

* **SDO/AIA** — Atmospheric Imaging Assembly
* **SDO/HMI** — Helioseismic and Magnetic Imager
* **OMNI** — solar-wind measurements

## Tools

* **Python**
* **SunPy**
* **Astropy**
* FITS-based astronomical data workflows

## Research Applications

The scripts are intended to support workflows such as:

* Solar FITS-data retrieval
* Solar-image processing
* Active-region analysis
* Magnetic and coronal observations
* Comparison of solar observations with solar-wind measurements
